植物大战僵尸 · KARDS   V1.2.0
====================================

【怎么开始】
  1) 双击 index.html，用 Chrome 或 Edge 打开
  2) 封面点「本机双人」或「竞技场」，不用搭卡组就能直接开打


【文件说明】
  index.html       游戏本体
                   整个游戏都装在这一个文件里（含卡图、桌饰画稿），
                   单独把它发给别人也能玩。
  游玩说明.html    玩法、操作、卡组规则、常见问题，建议先看一遍
  README.txt       本文件


【三件事要知道】
  · 单机玩法（本机双人 / 竞技场 / 回忆之旅 / 图鉴）完全离线。
    「联机对战」首次需要联网加载模块，加载不出来就换网络。
  · 卡组固定 39 张。卡组、主题、桌饰的选择存在浏览器本地，
    换浏览器或清缓存会丢，重要卡组请用构筑器里的「导入 / 导出」
    保存成一段字符串。
  · 完整规则和词条速查表在游戏内封面「规则讲解」里。


版本 V1.2.0 · 单文件网页游戏 · 无安装 · 无账号 · 不联网也能玩
